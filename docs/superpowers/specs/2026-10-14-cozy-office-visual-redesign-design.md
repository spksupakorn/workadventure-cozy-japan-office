2. pack หลักเป็นของในบ้านอย่างเดียว ไม่มีของนอกอาคาร สวนจึงต้องวาดเองทั้งหมด
3. ไม่มีขั้นตอนเทียบภาพ test ทุกตัวตรวจได้แค่ความถูกต้อง ตรวจความสวยไม่ได้

## 2. การตัดสินใจของผู้ใช้

1. เขียน generator ใหม่ให้รองรับมุมมอง 3/4 (ทางเลือก A)
2. สวนใช้ GuttyKreum "The Japan Collection: Japanese City (Free Version)" (https://guttykreum.itch.io/free-japanese-city-game-assets) ผู้ใช้ดาวน์โหลดและ unzip ไว้ที่ `maps/cozy-office/tilesets/guttykreum-city/` ของที่ pack นี้ไม่มี ให้ทำแบบ tsuboniwa ด้วยของจาก pack หลัก
3. อนุมัติกฎด้านภาพ (ข้อ 3) และผัง 44x30 (ข้อ 4) โดยให้สวนอยู่ตำแหน่งเดิม คือเข้าผ่าน pantry และ play corner

## 3. กฎด้านภาพ

### ผนังแบบ 3/4
ห้องทุกห้องประกาศด้วย `Room` แล้ว generator ประกอบผนังให้เอง
- **ผนังด้านเหนือ:** สูง `NORTH_ROWS` แถว คือขอบบน 1 แถว + หน้าผนัง ค่าเริ่มต้น `NORTH_ROWS = 3` ต้องยืนยันจาก pack ใน task แรกของ plan ถ้าค่าจริงไม่ใช่ 3 ให้ขยายผังทั้งแถว โดยคงลำดับห้องและตำแหน่งประตูเดิม
- **หน้าผนัง:** แบ่งเป็นช่วง แต่ละช่วงเลือกแบบได้: `plain`, `window`, `shoji`, `cabinet`, `scroll` ถ้าไม่ระบุ generator สลับ `plain` กับ `window`
- **ผนังด้านข้างและด้านใต้:** เส้นขอบหนา 1 tile มีชิ้นมุมแยกสำหรับมุมทั้ง 4 และรอยต่อรูปตัว T เมื่อห้องติดกัน
- **ประตู:** ประตูบนผนังด้านเหนือเจาะทะลุทุกแถวของผนังด้านเหนือ และวางภาพประตูบานเลื่อนบนหน้าผนัง ประตูด้านข้างหรือด้านใต้เป็นช่องเปิดในเส้นขอบ
- **นอกอาคาร:** ช่องที่ไม่อยู่ในห้องหรือโซนนอกอาคารเป็น tile ว่าง (แสดงเป็นสีดำ) และเดินไม่ได้

### พื้น
- พื้นไม้ใช้ลายไม้ของ pack
- ทาทามิ: helper `tatami_mats(rect)` ปูเสื่อขนาด 1x2 และ 2x1 สลับกันตามแบบใน Screenshot2 เสื่อทุกผืนต้องมีขอบ
- Genkan ใช้พื้นหิน
- พรม: ใช้ object พรมของ pack วางใต้โต๊ะประชุม โคทัตสึ และโต๊ะกินข้าว

### ความหนาแน่น
- ทุกห้องต้องมีของอย่างน้อย 1 ชิ้นชิดหน้าผนังด้านเหนือ (ชั้นหนังสือ ตู้ เคาน์เตอร์ หรือฉาก)
- ทุกห้องที่ภายในกว้างตั้งแต่ 5x4 ขึ้นไปต้องมีพรม หรือโคม andon หรือต้นไม้ อย่างน้อย 2 ชิ้น
- ห้ามมีพื้นที่ว่างรูปสี่เหลี่ยมจัตุรัสใหญ่กว่า 4x4 tile (ดูการตรวจในข้อ 6)

### แหล่งภาพ
ใช้ตามลำดับนี้:
1. pack หลัก (`tilesets/guttykreum/Tilemap/MainTileMap.png`)
2. Japanese City Free (`tilesets/guttykreum-city/`) สำหรับหญ้า ทางหิน ต้นไม้ น้ำ และของในสวน
3. sprite ที่วาดเอง สำหรับของที่ทั้งสอง pack ไม่มีเท่านั้น

sprite ที่วาดเองต้อง:
- ใช้สีจาก palette ที่ดึงจาก pack หลักและ City pack (`tools/palette.py`)
- มีเส้นขอบสีเข้ม 1 px แบบเดียวกับ pack
- ไม่ใช้สีสดเกินกว่าที่มีใน pack

## 5. การเปลี่ยนแปลงใน generator

| ไฟล์ | การเปลี่ยนแปลง |
|---|---|
| `tools/mapgen/model.py` | เพิ่ม `Room(key, rect, floor, north_wall=())`, `Door(x, y, rows)`, `Outdoor(key, rect, floor)` และ `WallSpan(start, width, style)` |
| `tools/mapgen/rooms.py` (ใหม่) | `build_shell(rooms, doors, outdoors, kit) -> tuple[list[Fill], list[Stamp], list[Rect]]` แปลงห้องเป็น `Fill`/`Stamp` ของผนังและพื้น พร้อมช่องประตู และ `tatami_mats(rect) -> list[Stamp]` |
| `tools/mapgen/render.py`, `validate.py`, `tmj.py` | คงเดิม เพราะ `rooms.py` คืนค่าเป็น `Layout` แบบเดิม |
| `tools/vocab.py` | เพิ่มชื่อชิ้นผนัง (ขอบบน มุม รอยต่อ T ด้านข้าง ด้านใต้ หน้าผนังแต่ละแบบ ประตูบานเลื่อน) เสื่อทาทามิ พรม โคม andon ม้วนภาพ ชั้นหนังสือ และของในสวน |
| `tools/layout.py` | เขียนใหม่ตามข้อ 4 ด้วย `Room`/`Door`/`Outdoor` แทน `Fill` ของผนัง |
| `tools/tiles.py` | เขียน mapping ใหม่ทั้งหมด และเพิ่ม tileset ของ City pack |
| `tools/draw_custom.py` | วาด sprite ใหม่ตามกฎใน palette ของ pack และวาดเฉพาะของที่ทั้งสอง pack ไม่มี |
| `tools/palette.py` (ใหม่) | ดึง palette จาก pack และใช้ใน `draw_custom.py` กับ test |
| `tools/render_preview.py` (ใหม่) | render `.tmj` เป็น PNG, ภาพเทียบกับ Screenshot ของ pack และภาพ swatch ของ tile ทุกชื่อ |

## 6. การตรวจ

ใช้การตรวจทั้งหมดใน spec v1 ข้อ 6 และเพิ่มดังนี้

### ตรวจอัตโนมัติ (test)
1. **ผนัง:** test ของ `rooms.py` ตรวจว่าผนังด้านเหนือหนา `NORTH_ROWS` แถว ด้านข้างและด้านใต้หนา 1 แถว ประตูบนผนังด้านเหนือเจาะครบทุกแถว และช่องนอกอาคารเดินไม่ได้
2. **ทาทามิ:** ทุกช่องใน rect ถูกเสื่อคลุม เสื่อไม่ซ้อนกัน และมีทั้งเสื่อแนวตั้งและแนวนอน
3. **Palette:** ทุก pixel ที่ไม่โปร่งใสใน `tilesets/custom/` ต้องมีสีห่างจากสีใดสีหนึ่งใน palette ของ pack ไม่เกินค่าที่กำหนด (RGB Euclidean distance ≤ 24)
4. **ความโล่ง:** พื้นที่ว่างรูปจัตุรัสที่ใหญ่ที่สุดในแต่ละห้อง ต้องไม่เกิน 4x4 พื้นที่ว่างคือช่องที่เดินได้ ไม่มีเฟอร์นิเจอร์ และไม่ใช่ประตู
5. **ความหนาแน่น:** ทุกห้องมีของชิดหน้าผนังด้านเหนือ ห้องที่ภายในตั้งแต่ 5x4 มีพรม โคม หรือต้นไม้รวมกันอย่างน้อย 2 ชิ้น

### ตรวจด้วยตา (gate)
1. **Swatch:** ทุกครั้งที่แก้ `tiles.py` ให้ render `tools/out/tiles-swatch.png` ที่แสดงทุกชื่อพร้อมภาพของมัน แล้วผู้ทำงานต้องเปิดดูก่อน commit ห้ามเลือก tile id จากเลขบน sheet อย่างเดียว
2. **Preview:** ทุกครั้งที่ build ให้ render `tools/out/preview.png` และ `tools/out/compare.png` (preview วางข้าง Screenshot ของ pack) ผู้ทำงานต้องเปิดดูก่อนส่งให้ผู้ใช้
